# 手机界面调整与复测

本轮修改针对 2026-10-07 反馈的组卡难用、决斗按钮过小、详情／历史错位和设置无法触摸关闭。只更新网页静态资源，服务器配置与对局协议沿用现有版本。

## 当前交互

- 组卡页在手机显示「卡组管理／编辑卡组／搜索卡片」三个入口。同一份编辑草稿在页面之间保留；旋转屏幕、切换显示语言也保留未保存的卡片和卡组名称。管理页提供导入、新建、下载；搜索结果提供加入主卡组／备牌按钮；编辑页提供移动、删除、保存。
- 手机触摸卡片才打开详情，触摸加入按钮不会同时触发桌面悬停预览。主要组卡按钮及决斗工具按钮至少 44 CSS px；卡片网格按可用宽度排列，列表使用独立滚动区域。
- 组卡图片采用原生延迟加载；未加载完成或图片请求失败时显示卡名，占位仍可触摸查看效果，不阻塞组卡操作。
- 决斗仅缩放场地与卡片，生命值、计时和工具栏保持正常尺寸。竖屏生命值在顶部，横屏在左侧；场地避开信息栏和底部工具栏。
- 卡片详情和操作历史在竖屏使用底部面板，横屏使用侧边面板；内容可以滚动，每个面板有右上「关闭」及叉号。聊天沿用底部面板，保留输入框和发送按钮。
- 首页及决斗工具栏均可打开设置。设置有底部「关闭」、右上叉号和点击遮罩关闭，桌面仍支持 Esc。
- 表示形式、效果选项和多张选卡弹窗按手机宽度换行。对局选择弹窗的减号用于暂时收起，向上箭头恢复；出现新的选择时自动展开，不自动替玩家回答。
- 决斗准备页改为顶部文字操作、可滚动玩家卡片和底部准备／开始按钮，入场与选择卡组保持未准备；手机聊天可以触摸关闭，语言选择不再悬浮遮挡底部。Tag 等待页按四席全员准备判断，完整双打实战尚未适配／验收。详情及回归见 [准备页说明](waitroom-ui.md)。

## 本地回归

```powershell
npm run test:mobile-ui
```

脚本先生成已锁定的环境资源，再自行启动临时 Vite 和无头浏览器，优先使用 Windows 上安装的 Edge；也可设置 `PLAYWRIGHT_BROWSER_EXECUTABLE`。它使用本地模拟的界面状态，不连接正式服务器、不使用玩家账号。

覆盖 390×844、844×390 和 320×640 的触控视口：新增卡组、搜索、加入、换区、删除、保存、YDK 导出、筛选关闭、设置关闭、决斗菜单、触摸手牌操作封包、表示形式／效果选项、最小化恢复、卡片详情及历史触摸滚动。另检查草稿在旋转和四语切换后保持、桌面设置 Esc 关闭，以及卡图请求失败时卡名可见、详情可操作。

截图与结果写入 `.audit-tmp/mobile-ui/after/`，该目录不提交到 Git。修复前截图保存在 `.audit-tmp/mobile-ui/before/`，仅作为本机审查证据。`npm run test:smoke` 验证构建包的桌面和手机入口；`npm run test:local-wss` 验证隔离 SRVPro 的真实 Core／WSS 生命周期，二者不等同手机真机验收。

2026-10-07 本轮结果：上述三个触控视口、桌面 Esc、卡图失败占位回归均通过；类型检查、lint、构建与静态入口冒烟通过。隔离 SRVPro 已通过普通房开局／结束后首次再次入场，以及 TT G1–G3、两次换备和退出保留昵称／密码。当前正式测试隧道的可信 TLS／WSS 101 握手也通过。完整修复前后截图报告在本机 `.audit-tmp/mobile-ui/report.html`。

## 手机上仍需亲自核验

Edge 触控模拟已经能验证布局和操作事件，但不能证明 Android Chrome／iOS Safari 上的文件选择、下载、输入法、刘海手势区、后台恢复和音频行为。需在两类真机上横竖屏完成完整比赛及换备。正式服禁表 hash 差异已定位并准备修正版，正式替换与复验见 [禁表修正](banlist-diagnosis.md)；界面调整没有改变卡池或禁表。
