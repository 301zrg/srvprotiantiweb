# 手机界面调整与复测

记录 2026-10-07 至 2026-10-10 的组卡、换备、决斗按钮、详情／历史和设置触摸操作调整。只更新网页静态资源，服务器配置与对局协议沿用现有版本。

## 当前交互

- 组卡页在手机显示「卡组管理／编辑卡组／搜索卡片」三个入口。同一份编辑草稿在页面之间保留；旋转屏幕、切换显示语言也保留未保存的卡片和卡组名称。管理页提供导入、新建、下载和另存／分享；搜索结果提供加入主卡组／备牌按钮；编辑页提供移动、删除、保存。
- 手机编辑区使用紧凑网格：390 px 竖屏一行六张，320 px 一行四张，844 px 横屏一行十三张。移动／删除放在卡片下方的三点菜单中，按钮和菜单项保持至少 44 px 触摸尺寸；点击卡图仍可看详情。桌面沿用直接操作按钮。
- 短横屏下可滚动整个编辑区，将组卡工具栏滚出可视范围，主卡组／额外／副卡组都可向下浏览。底部额外留出 120 px 加安全区空间，最后一行也能滚到方便操作的位置。搜索与管理入口继续使用独立滚动区。手机卡图不启动拖拽，避免抢占滑动手势；加入／移动／删除用触摸按钮和菜单，桌面仍可拖拽。
- 换备页使用紧凑网格。手机卡片下方直接显示带换区图标的目标区域按钮，点一次即移入备牌或移回主／额外卡组；无须打开浮动菜单，避免最右列定位闪烁。可访问名称保留完整移动目标和卡名。点卡图查看详情，关闭后继续换备；主卡、额外、备牌数量在顶部显示。重置／确定固定在滚动区之外，手机横竖屏均可触达。
- 换备卡片区使用独立原生纵向滚动，其高度绑定实际可用视口，避免内容把容器撑到屏幕下方。底部按可用高度保留 24–104 px 加安全区余量；极短横屏不会因固定留白把最后一排按钮推到滚动区上方，最后一排按钮可以完整滚到语言选择器上方。旋转不清空换备草稿；重置始终恢复本次进入换备页时的卡组。
- 换备的重置、数量校验和双方换备完成提示显示在页内，不使用遮住顶部操作按钮的悬浮消息；继续移动卡片时清除上一条提示。四种语言均按当前选择显示。
- 每个管理列表项新增分享图标；点击后将该项的卡组导出为 YDK，直接打开系统的另存／分享面板。不支持、分享权限拒绝或能力检测失败时回退为同内容的 YDK 下载；用户取消时不强制下载。保留卡片顺序、重复张数和各分区，点击其他卡组的分享图标不会替换当前编辑草稿。
- 手机触摸卡片才打开详情，触摸加入按钮不会同时触发桌面悬停预览。主要组卡按钮及决斗工具按钮至少 44 CSS px；卡片网格按可用宽度排列，列表使用独立滚动区域。
- 组卡图片采用原生延迟加载；未加载完成或图片请求失败时显示卡名，占位仍可触摸查看效果，不阻塞组卡操作。
- 决斗仅缩放场地与卡片，生命值、计时和工具栏保持正常尺寸。竖屏生命值在顶部，横屏在左侧；场地避开信息栏和底部工具栏。
- 决斗单卡详情和额外／墓地／除外／素材查看在手机竖屏使用约 34% 视口高度的底部面板，横屏使用 280 px 右侧面板；内容可以原生滚动，不显示阻挡场地的遮罩，面板避开底部决斗工具栏。「关闭」保持至少 44 px，详情卡图缩至 72 px（短横屏 64 px），卡列表改为紧凑多列并显示区域和张数。操作历史／聊天继续使用较大可滚动面板。
- 手机选卡弹窗使用约 52–70 px 的卡图网格，少量候选也不会撑大图片。点击卡图只选中／取消选中，独立的「查看卡片」按钮打开效果详情；关闭详情后选择保留，提交／取消／完成会收起详情。桌面保留点击选卡并查看详情的行为。
- 首页及决斗工具栏均可打开设置。设置有底部「关闭」、右上叉号和点击遮罩关闭，桌面仍支持 Esc。
- 设置的「消息」页提供「弹出服务器消息」，默认开启并在当前浏览器保存。关闭会收起正在显示的服务器聊天通知，并禁止后续服务器聊天通知；聊天记录照常保留。其他玩家聊天通知、决斗选择和错误提示仍正常显示。重新开启不补弹已略过的服务器消息。
- 网页收到入房确认后，自动按当前语言发送 `/zh`、`/en`、`/ja`、`/ko`；重入房也会重新发送。语言指令只切换服务端文字，不改变卡组、准备状态或协议版本。隔离本地 SRVPro 四语入房及首次重入房已通过，命令见 [联调说明](wss-integration.md)。
- 表示形式、效果选项和多张选卡弹窗按手机宽度换行。对局选择弹窗的减号用于暂时收起，向上箭头恢复；出现新的选择时自动展开，不自动替玩家回答。
- 手机决斗准备页优先展示玩家席位；卡组选择独立成块，数量与加入观战按钮共用底部一行，房间详细规则可以展开。顶部保留语言、聊天、退出，准备／开始固定在底部，短横屏中间内容独立滚动。入场与选择卡组保持未准备。Tag 等待页按四席全员准备判断，完整双打实战尚未适配／验收。详情及回归见 [准备页说明](waitroom-ui.md)。

## 本地回归

```powershell
npm run test:mobile-ui
npm run test:deck-share-ui
npm run test:side-ui
npm run test:mobile-duel-ui
```

手机回归脚本先生成已锁定的环境资源，再自行启动临时 Vite 和无头浏览器，优先使用 Windows 上安装的 Edge；也可设置 `PLAYWRIGHT_BROWSER_EXECUTABLE`。它使用本地模拟的界面状态，不连接正式服务器、不使用玩家账号。卡组分享脚本针对已经启动的静态测试站点（默认 `http://127.0.0.1:4173`，或设置 `SMOKE_URL`），模拟浏览器分享 API，验证文件内容与用户手势；这不等同真机系统分享面板验收。

换备回归脚本构建独立的静态测试站点，使用 60 主卡／15 额外／15 备牌的合成数据和本地卡库，不连接正式 WSS。仅测试构建注入状态入口，正常发布包不包含该入口。检查四语目标按钮、最右列连续点击不弹菜单且一次只移动一张、卡图密度、真实触摸事件滑动、底部最后一张卡可达、工具栏尺寸、旋转及可用高度变化、重置、数量超限不发送，以及有效换备的 `UPDATE_DECK` 原始卡号／顺序／重复张数。截图和测量保存至本机 `.audit-tmp/side-ui/after/`；不等同 iOS Safari 真机验收。

`test:mobile-duel-ui` 同样构建仅注入合成状态的独立静态站点，不接正式服务器。覆盖四语 × 390×844、844×390、320×640、568×320、1280×800，检查等待页初始不发包、手动准备与开始条件、四席双打人数约束、详情大小及底部按钮避让、实际触摸召唤封包、卡列表最后一张卡及关闭、单选／多选和原始响应、手机预览不改变选择、旋转保留选择。结果与截图保存在 `.audit-tmp/mobile-duel-ui/after/`，浏览器动画结束后再截图，候选检查只统计当前可见的选择弹窗。

覆盖 390×844、844×390 和 320×640 的触控视口：卡图密度、横屏手势滚动和底部操作余量、新增卡组、搜索、加入、换区、删除、保存、YDK 导出、筛选关闭、设置关闭、服务器消息弹出开关和刷新保留、决斗菜单、触摸手牌操作封包、表示形式／效果选项、最小化恢复、卡片详情及历史触摸滚动。另检查草稿在旋转和四语切换后保持、桌面设置 Esc 关闭，以及卡图请求失败时卡名可见、详情可操作。卡组分享检查另覆盖桌面视口、原始 YDK 内容、即时手势、权限拒绝回退、取消不下载和不覆盖草稿；共用导出工具还须通过 `npm run test:replay-share-ui`。

截图与结果写入 `.audit-tmp/mobile-ui/after/`，该目录不提交到 Git。修复前截图保存在 `.audit-tmp/mobile-ui/before/`，仅作为本机审查证据。`npm run test:smoke` 验证构建包的桌面和手机入口；`npm run test:local-wss` 验证隔离 SRVPro 的真实 Core／WSS 生命周期，二者不等同手机真机验收。

## 更新现有测试站点

通常将 PR 合入 `deploy/cloudflare`，由已有 Cloudflare Git 构建自动更新 `https://ocg1103nexus.com/`；原 `workers.dev` 地址仍指向同一 Worker。配置见 [自动部署](cloudflare-ci.md)。本轮只更新网页，不要求重启 SRVPro、Nginx 或已由 PM2 管理的隧道。

需要手工打包时，使用当前仍在线的公开 WSS 地址；下面的隧道域名是占位符，应替换后再执行：

```powershell
$env:VITE_DUEL_WS_URL = 'wss://你的现有隧道域名/neos'
npm run build:cloudflare
npm run package:test -- --wss-url $env:VITE_DUEL_WS_URL --site-origin https://ocg1103nexus.com
```

隧道若已重启，先替换为新的真实 URL。自动部署成功或手工上传后，桌面用 Ctrl+F5，手机重新打开页面；按 [部署信息](https://ocg1103nexus.com/deployment-info.json) 核对提交版本，再横竖屏测试组卡、换备和决斗。

## 手机上仍需亲自核验

Edge 触控模拟已经能验证布局和操作事件，但不能证明 Android Chrome／iOS Safari 上的文件选择、下载、输入法、刘海手势区、后台恢复和音频行为。需在两类真机上横竖屏完成完整比赛及换备。正式服禁表 hash 差异已定位并准备修正版，正式替换与复验见 [禁表修正](banlist-diagnosis.md)；界面调整没有改变卡池或禁表。
