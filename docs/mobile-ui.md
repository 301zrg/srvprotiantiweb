# 手机界面调整与复测

本轮测试预览的连锁询问收起后，手机竖屏在场地上方预留独立一行；窗口通过实际高度更新布局变量，关闭／离开时释放。场地与底部历史／操作按钮均不被该行覆盖，旋转后保留待处理请求。练习的结果提示条同样有独立空间，不能抢占手牌或操作控件。

超量素材按原生 overlay index 分配整数层级，避免同层 DOM 顺序使一张素材遮住另一张。宿主始终高于素材；练习过渡帧先按 index 重建素材身份。五种屏幕尺寸的回归同时检查每张素材的真实命中区域、详情身份、格内边界、聚焦恢复与去除／再叠／宿主出入场，不能只检查数量角标。

记录 2026-10-07 至 2026-10-10 的组卡、换备、决斗按钮、详情／历史和设置触摸操作调整。只更新网页静态资源，服务器配置与对局协议沿用现有版本。

“画面与消息”的“操作面板位置”默认左侧，可改为右侧并保存在浏览器。准备页聊天、决斗横屏侧栏及其停靠详情／反馈、测试手牌侧栏和记录抽屉即时使用同一设置。场地同时让出选定侧空间，切换不重建对局、请求或聊天组件；手机竖屏保留场地和底部按钮行，聊天／操作抽屉从所选侧展开。必要选择面板依所选侧对齐，收起后的竖屏提示行仍保留独立空间。

测试版反馈回归（2026-10-31）：`npm run test:practice-mobile-feedback` 用真实 Core 在测试手牌中发动强欲而谦虚之壶，检查手机竖屏／横屏 3 张同排、确认按钮可见，以及手机文字记录（全部 7 行可见、无卡图、卡名打开详情）和电脑图文记录；`npm run test:mobile-spectator-menu` 另检查对局聊天默认正序、切为倒序及跟随操作记录；`npm run test:client-settings`、`npm run test:observer-seat`、`npm run test:effect-audio` 覆盖新设置的默认值与持久化、观战座位换算，以及音效不积压。均为本地 Edge 与合成／本地 Core，iPhone 真机音效仍需实机确认。
