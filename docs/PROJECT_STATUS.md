## 已确认的限制

- 在线没有累计队列上限。单次 WS 消息与半包缓冲限制不能约束累计待消费量。
  用户于 2026-10-10 决定暂不实施 B，保留动画连续性，接受长时间后台／慢消费导致积压或卡顿；
  观战卡顿可退出重进。当前没有新的线上内存事故复现，也没有因此改变动画或在线封包。
- sessionStorage 回填不等于自动恢复活跃对局。刷新后的玩家仍需手动入房、选择 G1 原始卡组；
  原有页面的恢复使用冻结字节。服务器是否允许接续及计时不由网页延长。
- 完整 Tag 双打尚未适配；四席准备页不是完整双打能力。
- YRP1、Tag、谜题、其他版本／非 UNIFORM 以及旧 `.yrp3d` 暂只保存与下载。
  录像头没有脚本摘要，支持格式不证明所有历史裁定一致；错误／响应耗尽按实际内容停止，不补造胜负。
- 浏览器卡组／录像是本地数据。更换网站 origin、浏览器或清站点数据前需导出；临时内存副本刷新会丢失。
- 原 12.7 MB 包体属于录像资源加入前的在线首版历史测量。当前包体、首屏和首次播放成本须按对应构建测量。
