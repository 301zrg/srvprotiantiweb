## 使用

顶部「录像列表」进入本地录像库，导入标准 YRP2 后点击播放。默认完整场地视图，也可随时点「列表视图」切回原区域列表。

- 显示双方五个怪兽位、五个魔陷位和场地位、手牌、主卡组、额外、墓地及除外区。视角切换同时调整玩家姓名、LP、卡位和攻击箭头。
- 逐个显示抽卡、移牌、召唤／盖放、表示形式变化、发动／处理连锁、攻击、LP 变化、指示物和回合／阶段变化。移牌有移动提示，攻击使用箭头，连锁标序号。
- 攻守姿态、表里侧、实时攻守数值、素材及指示物沿用列表状态版。默认里侧卡显示卡背，双方手牌可查；「查看里侧卡片」允许检查隐藏内容，实际表示形式保留。
- 点卡片或牌堆会暂停。牌堆弹层显示该区卡片，进一步点卡片查看详情；手机有可点的关闭按钮。暂停后可继续或单步，切到后台也暂停。
- 场地按窗口尺寸缩放，可放大到 1.5×／2×，在场地内滚动，点「恢复大小」回到适配尺寸。大量手牌允许重叠排列；卡片详情和列表视图用于仔细检查。
- 桌面默认一屏完整显示双方手牌、所有卡位及牌堆。按可用宽度与实际剩余高度中的较小限制等比例缩放，在完整可见的前提下尽可能大，不额外限制大屏放大倍数；缩紧工具栏间距，玩家姓名、手牌数量、LP 和播放工具仍可见。窗口改变或展开里侧卡提示后会重新适配。「恢复大小」回到一屏完整场地；主动放大后才需要在场地内滚动。点击卡片或牌堆仍自动暂停。手机竖屏／横屏保留原有比例与触控布局。
- 播放速度支持 0.5×、1×、2×、4×、8×、16×。移动动画随倍速缩短，逐个处理展示步骤，不跳过录像响应；内核计算较慢的设备实际速度可能低于所选倍速。

## 重演与数据边界

录像仍由固定 `706-v1` Core 和旧裁定 Lua 重算，保持原来的格式检查、响应、脚本和 `special.lua` 处理，不把场地展示状态写回内核，也不创建联机 WSS。

之前一次 Core 返回一批消息后，只展示这批的最终局面。本分支在显示层把该批消息转换成有限动作队列，播放／单步逐个消耗；每批最后一帧仍使用完整、未缓存的 Core 查询结果校准。仅缓存一批，回合跳转、重新开始、退出会清理队列。暂停发生在动作之间，已开始的短 CSS 动画可以完成。

当前是场地重演首版，不能称为完整复刻原版 YGOPro 动画。尚未逐项实现全部效果演出和提示；未知的展示动作会在该批末校准为内核实际状态。Core 本身遇到不支持或错误数据仍按原规则停止播放，不猜测后续操作。素材以数量和详情展示，尚无逐张叠放动画。

格式支持范围与本地存储规则不扩大：见 [录像使用说明](replay-usage.md)。Tag 双打等暂不支持播放的格式继续仅保存／下载。

## 验证和发布

本地命令：

```powershell
npm ci --include=dev
npm run build:static
npm run preview:static
```

打开 `http://127.0.0.1:4173/#/replays`。可导入 `tests/fixtures/replay/` 下的四份脱敏原生测试录像。

自动检查：

```powershell
npm run test:replay-scene
# 先启动预览，再执行浏览器检查；SMOKE_URL 可指定其他本地端口。
npm run test:replay-field-ui
npm run test:replay-ui
npm run test:replay-state-ui
```

本轮证据：四份自建原生录像共 2,090 批 Core 输出、2,917 个展示步骤；每批末牌面与 LP 都与实际 Core 查询完全一致，已有帧不被修改。受控浏览器场景在桌面、390px 竖屏、320px 窄屏、844px 横屏检查移动后卡片身份、攻守表示、连锁、攻击、指示物、视角、暂停、回合跳转清理旧连锁、牌堆、放大与列表回退；真实 Core 浏览器检查导入／下载／刷新／播放／单步／重新开始／回合跳转／视角／关闭，播放全程无 WSS。

桌面尺寸回归：1280×800、1920×1080、1024×768、2560×1440、1280×1100 和较短桌面窗口检查双方手牌、所有卡片、卡位与牌堆都在默认场地范围内，场地及玩家信息一屏可见，场地和页面均无需滚动；宽度或剩余高度至少有一项被充分利用。展开里侧卡提示、改变窗口尺寸及恢复大小后仍完整适配，查看卡片自动暂停。四种桌面／触屏尺寸均检查 16× 播放仍展示移牌、表示变化、连锁、攻击、指示物与伤害，不跳过动作，最终 LP 与牌面保持一致。

确认卡片产生的暂停不再额外消费响应，见 [兼容修复](replay-usage.md)。用户正式服问题样本在本地加入同一场地检查后，合计 3,793 批、5,158 个展示步骤均通过完整查询对照；问题样本的 774 条响应全部消费，第 35 回合按记录到此结束，不额外猜测胜负。私有样本仅从 `SRVPRO_REPLAY_FIXTURE` 指定的本地忽略目录读取，不纳入 Git。
