# 录像播放页改为对局界面布局（已实施，测试版）

2026-10-26 用户确认目标：录像播放时整页与联机对局界面一致，而不只是牌桌一致。用户采纳下列五项选择及审阅补充，并授权实施、仅发布测试版。实现见 [共享对局外壳](ARCHITECTURE.md#共享对局外壳)；实施中“更多”由下拉菜单改为停靠面板（短横屏下拉放不下全部操作），正常高度宽屏侧栏只固定常用操作，避免控件区滚动遮住生命值。
基于测试版 `889f4c07`（共享牌桌已上线测试站）。

## 现状

| 部分 | 联机对局（`/duel`） | 录像播放（`/replays` 内） |
| --- | --- | --- |
| 页面外框 | 隐藏网站顶栏，全屏对局 | 保留顶栏；标题、按钮条、进度行、动作行、玩家行纵向堆叠，牌桌在下方框内 |
| 宽屏（横屏 ≥480 px） | 侧栏：双方生命值／计时、回合与阶段说明、阶段条、操作菜单、操作记录／聊天标签 | 无侧栏；12 个按钮横排 |
| 竖屏 | 顶部双方生命值，底部阶段条与图标工具栏，记录／聊天抽屉 | 按钮换行堆叠，牌桌在下方 |
| 卡片详情／牌堆 | 停靠在侧栏（宽屏）或底部面板 | 右侧抽屉 |
| 背景 | 对局底层渐变（Underlying） | 页面纯色，牌桌带边框 |

联机侧栏的组件直接读取在线 `matStore`／`roomStore`，录像不能直接套用；`replayStore` 是旧的开发用服务器回放，不是本地录像，不复用。

## 方案

**共享对局外壳，录像只提供数据和按钮。** 把联机侧栏／竖屏布局拆成只接收参数的展示组件，联机和录像各自提供数据：

| 新共享展示件（`ui/Shared/DuelShell/`） | 联机数据来源 | 录像数据来源 |
| --- | --- | --- |
| 外壳布局：宽屏侧栏＋牌桌区；竖屏顶部生命值＋底部工具栏；左右位置跟随设置 | 不变 | 同一外壳 |
| 生命值栏（名字、LP、手牌数，计时可选） | `matStore`／`roomStore` | 录像帧的名字、LP、手牌数（无计时） |
| 回合说明（第 N 回合 · 玩家 · 阶段） | 在线回合状态 | 录像帧回合／阶段 |
| 阶段条 `PhaseBar`（已共享） | 可点击切换阶段 | 只读高亮当前阶段 |
| 记录区标签 | 操作记录／聊天 | 录像操作记录（现有事件列表）；无聊天 |
| 详情／牌堆面板 `DuelPanel`＋共享详情正文 | 不变 | 由右侧抽屉改为同款停靠面板 |

**录像的按钮放进侧栏菜单位置**（宽屏两列网格，与联机菜单同样式）：

- 常用：继续播放／暂停、单步、播放速度、跳到回合（回合输入）、切换视角、重新开始。
- 次要：音效、查看里侧卡片、列表视图、放大／恢复、下载、提取卡组、设置、退出播放。
- 当前动作（“阶段变化 · 卡名”）放在联机提示条的位置（侧栏反馈槽／竖屏顶部）。

**竖屏与手机**：顶部双方生命值，底部阶段条 + 一行图标按钮（播放／暂停、单步、速度、记录、更多），其余收进“更多”菜单；按钮至少 44 px。

**页面**：播放时隐藏网站顶栏（与对局相同），“退出播放”回到录像库；牌桌使用对局底层背景、去掉外框；列表视图保留为同一外壳内的另一种内容。

## 审阅补充（已确认）

1. **短横屏：** 现有短横屏侧栏关闭控件区滚动、按钮 30 px。录像侧栏在高度不足 600 px 时只放常用操作（播放／暂停、单步、速度、更多），其余进入“更多”菜单；568×320、844×390 下所有操作、关闭和退出都必须可点击。正常高度的宽屏侧栏显示全部按钮。
2. **背景：** 对局底层 Underlying 改为接收“当前回合是否为下方玩家”，联机由在线状态计算，录像由当前帧计算。在线计时、阶段响应、聊天仍只在联机侧。
3. **牌桌尺寸：** 删除录像页对旧标题、按钮条、进度行的测量；牌桌按外壳分配的区域（与联机相同的牌桌区）适配，主动放大只在牌桌区内滚动，控制栏不动。
4. **状态提示：** 加载中、跳转中、错误、里侧显示提示、当前动作，以及“重演结束”和“记录到此结束”的区别都保留；错误与结束为常驻提示（宽屏在侧栏反馈位置，竖屏在生命值下方），不使用会自动消失的提示。
5. **状态保持与清理：** 播放／暂停时旋转、切换列表视图、开关面板不重建 Worker、不意外恢复播放；退出播放清理 Worker、声音与队列；顶栏仅在录像库地址带 `id`（播放器）时隐藏。联机选择未提交时旋转，草稿、计时与响应保持。测试手牌对共享组件做回归检查。

## 不改变

- 录像 Worker、Core 重算、展示步骤、倍速与暂停逻辑、音效、存储、提取、下载。
- 联机对局的行为、数据、请求与外观（外壳拆分后像素级对照）。
- 测试手牌页面：本轮不动；它已有自己的侧栏，可在本方案验收后另议是否套用同一外壳。

## 实施顺序

1. 拆共享外壳与展示件，联机侧栏／生命值栏改为传参使用；截图与原有对局回归确认联机不变。
2. 录像页接入外壳：生命值、回合说明、只读阶段条、录像按钮、记录标签、停靠详情与牌堆面板、隐藏顶栏。
3. 竖屏／手机工具栏与“更多”菜单；列表视图、放大滚动在新外壳内验证。
4. 更新录像相关浏览器脚本（选择器与布局断言），文档与状态；仅发布固定测试版。

## 验收

- 联机：对局／观战／换备脚本、iPad 五尺寸与手机三尺寸截图与当前一致。
- 录像：播放、单步、跳转、重开、倍速、视角、里侧、列表视图、放大、牌堆／详情、下载与提取全部可用；电脑、iPad 横竖屏、手机横竖屏无溢出，按钮 ≥44 px（短横屏沿用联机紧凑行）。
- 四语文案；离线不建立 WSS。真机与完整对局仍需人工验收。

## 需要确认

1. 播放时隐藏网站顶栏，用“退出播放”返回录像库（同对局）。建议：是。
2. 卡片详情和牌堆改为与对局相同的停靠面板。建议：是。
3. 手机竖屏底栏放：播放／暂停、单步、速度、记录、更多；其余进“更多”。可调整。
4. 测试手牌本轮不改，验收后再议是否统一。建议：是。
5. 仍只发布测试版，正式合入另行授权。
